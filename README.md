# 💻 CodSoft Python Programming Internship

Welcome to my **CodSoft Python Programming Internship** repository.

This repository contains all the projects completed during my internship. Each project focuses on solving real-world problems using Python while strengthening concepts such as problem-solving, algorithms, GUI development, and recommendation systems.

# 📂 Projects

## 🤖 Task 1 - Rule-Based Chatbot

A simple chatbot developed using Python that responds to predefined user inputs. The chatbot can greet users, tell jokes, share motivational quotes, and maintain an interactive conversation using rule-based logic.

**Key Concepts**
- Python
- Conditional Statements
- Functions
- Random Module
- User Input Handling

---

## 🎮 Task 2 - AI Tic-Tac-Toe

An AI-powered Tic-Tac-Toe game where the player competes against an unbeatable computer opponent. The AI uses the **Minimax Algorithm** to always choose the optimal move.

**Key Concepts**
- Python
- Minimax Algorithm
- Recursion
- Backtracking
- Game Logic

---

## 🎬 Task 4 - Movie Recommendation System

A GUI-based movie recommendation system developed using **Python**, **Tkinter**, **TF-IDF Vectorization**, and **Cosine Similarity**. The application recommends the top 10 similar movies based on the user's input.

**Key Concepts**
- Python
- Tkinter
- Pandas
- Scikit-learn
- TF-IDF
- Cosine Similarity
