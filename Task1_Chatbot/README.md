# 🤖 CodBot - Rule-Based Chatbot

## 📌 Project Overview

CodBot is a simple rule-based chatbot developed in Python as part of the CodSoft AI Internship. It interacts with users through predefined commands and provides useful responses such as greetings, jokes, motivational quotes, current date & time, and a built-in calculator.

The project is completely modular, with different Python files handling data, chatbot responses, and calculator functionality.

---

## ✨ Features

- 👋 Greets the user
- 😊 Responds to "How are you?"
- 😂 Tells random programming jokes
- 💡 Gives motivational quotes
- 📅 Displays the current date
- ⏰ Displays the current time
- 🧮 Performs basic calculations
  - Addition (+)
  - Subtraction (-)
  - Multiplication (*)
  - Division (/)
  - Modulus (%)
  - Exponent (**)
- 📖 Help menu
- 👋 Exit command
